## Возможности Markdown

### Форматирование текста

- **Полужирный текст**
- *Курсив*
- ***Полужирный курсив***
- ~~Зачёркнутый текст~~
- `Моноширный текст`

### Списки

**Маркированный список:**

- Первый пункт
- Второй пункт
- Третий пункт

**Нумерованный список:**

1. Первый шаг
2. Второй шаг
3. Третий шаг

**Вложенный список:**

- Основной пункт
  - Подпункт 1
  - Подпункт 2
    - Подподпункт

### Цитата

> Markdown — это лёгкий язык разметки, который легко читается как в сыром виде, так и после рендеринга. Он широко используется для оформления README-файлов, документации и блогов.

## LaTeX в Markdown

### Inline-формула

Площадь круга вычисляется по формуле $S = \pi r^2$.

Знаменитое уравнение Эйнштейна: $E = mc^2$.

### Блочная формула

Сумма первых $n$ натуральных чисел:

$$
\sum_{i=1}^n i = \frac{n(n+1)}{2}
$$

Интеграл Гаусса:

$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
