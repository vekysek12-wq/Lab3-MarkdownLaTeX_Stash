# Блоки кода и цитаты в Markdown

## Inline-код

Команда `git status` показывает текущее состояние репозитория.

Команда `git add .` добавляет все изменения в staging area.

## Блок кода с указанием языка

Пример на Python:

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Markdown")
```

Пример на C#:

```csharp
string name;
name = Console.ReadLine();
Console.WriteLine(name);
```

## Блок кода без указания языка

```
Это блок кода без подсветки синтаксиса.
Здесь может быть любой текст:
git init

```

## Цитаты

### Обычная цитата

> Markdown — это лёгкий язык разметки, который легко читается как в сыром виде, так и после рендеринга.
